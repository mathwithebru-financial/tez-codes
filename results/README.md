# Publishable Results

Only compact, non-sensitive result summaries are included.

Large prediction arrays, loss-series archives, model checkpoints, temporary SHAP chunks, and generated figures are excluded from the repository.

Compact outputs for the post-hoc Bartlett-HAC volatility robustness check are available in [`robustness/bartlett_dm_hln_v1/`](robustness/bartlett_dm_hln_v1/).

The detailed loss-differential series, spreadsheet workbook, and source/audit ZIP packages remain excluded. Their integrity hashes are recorded in the robustness folder.
